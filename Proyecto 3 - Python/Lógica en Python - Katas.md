Lógica en Python - Katas

Este repositorio contiene una colección de ejercicios de lógica en Python desarrollados como práctica para reforzar conceptos fundamentales de programación.


Archivo principal

"Logica_Katas_Python.py"

Este archivo incluye múltiples ejercicios de programación enfocados en lógica, estructuras de control, funciones y programación orientada a objetos.



Contenido

En este proyecto se trabajan los siguientes conceptos:

Funciones y funciones lambda
Uso de "map()", "filter()" y "reduce()"
Manejo de excepciones ("try / except")
Programación orientada a objetos, clases
Manipulación de strings y listas
Condicionales ("if", "elif", "else")
Recursividad



Ejercicios incluidos

Algunos ejemplos de ejercicios desarrollados:

Cálculo de frecuencias de letras
Filtrado de listas
Conversión de listas a números
Cálculo de factorial recursivo
Gestión de un árbol con clases ("Arbol")
Sistema de usuarios bancarios ("UsuarioBanco")
Procesamiento de texto
Cálculo de áreas de figuras geométricas
Validaciones con entrada de usuario



Cómo ejecutar el programa

1. Descarga el archivo "Logica_Katas_Python.py"

2. Ábrelo en Visual Studio Code

3. Ejecuta el archivo: Logica_Katas_Python.py



Requisitos

Python 3
Visual Studio Code
Notebook Jupyter



Objetivo

El objetivo de este proyecto es practicar y consolidar habilidades de programación en Python mediante ejercicios tipo "katas", mejorando la lógica y la resolución de problemas.
